# 🚀🚀 AGENTCODI Package Edition V.0.1.0

Want maximum freedom? Then download the package edition now. Decide for yourself how your development environment is set up.

Uses commands like:

apt update
apt install your-package-name

And simply install everything you need yourself.

Or even simpler, create a prompt so Codex can download your packages.

The previously pinned packages such as Node.js, npm, ripgrep or Python are no longer part of the APK.

These packages are no longer needed because you can now easily install the ones you need.

Package Edition runs exclusively in danger-full-access mode without the additional AGENTCODI workspace sandbox. Android’s app isolation remains active.

Important: This is an early version; errors may occur. If you encounter any errors, please report them to me.
