## AGENTCODI Package Edition v0.1.2

#### Responsive Chat & Terminal Improvements

This update focuses on improving the user experience on Android smartphones and tablets, with redesigned chat controls, a more flexible prompt editor, and better terminal readability.

#### Chat Interface

- Redesigned the conversation layout with compact model and reasoning effort selectors.
- Introduced a full-width, multiline prompt editor with a separate action toolbar.
- Improved accessibility of file imports, connectors, review actions, message sending, steering, and turn interruption.
- Added detailed dialogs for model descriptions and reasoning settings.
- Improved attachment management with inspectable file and connector lists and individual removal controls.
- Added responsive layout behavior for smaller screens, landscape orientation, and on-screen keyboards.
- Preserved draft content, cursor position, and essential controls during layout changes.

#### Terminal Improvements

- Fixed long command lines, directory paths, and package diagnostics being cut off on smartphone screens.
- Added support for displaying longer commands across up to three input lines.
- Improved terminal row and column calculations using actual font metrics and available screen space.
- Added automatic terminal resizing when the viewport dimensions change.

#### Compatibility & Validation

- Successfully tested on physical Android devices.
- Improved usability across different screen sizes and orientations.
- Retained support for English, German, and Simplified Chinese.
- Preserved existing runtime, package management, workspace, and session functionality.

Requirements: Android 10+ · ARM64-v8a

Version: 0.1.2 · Android versionCode: 5
